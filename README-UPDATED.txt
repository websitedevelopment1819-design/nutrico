How to use:
1. Extract this ZIP.
2. Open the extracted folder in VS Code.
3. Open the VS Code terminal in the project folder.
4. Run: npm install
5. Run: npm run dev

For production build:
- Run: npm run build

Note: node_modules and the old dist folder are not included. npm install recreates dependencies.
